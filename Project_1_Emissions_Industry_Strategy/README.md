# Project 1 — Emissions and Industry Strategy

## MFE 230G — Equity Markets

This project studies the relationship between emissions intensity, industry returns, portfolio performance, and factor exposures.

### Contents

- `MFE230G_HW1.ipynb` — main analysis notebook
- `data/` — emissions and Fama-French 49 industry return data
- `results/` — performance tables, factor-regression outputs, and figures
- `assignment/` — original assignment PDF

### Main Analysis

The project evaluates portfolios formed using emissions-related industry information and examines:

1. Industry-level return performance
2. High- versus low-emissions portfolio performance
3. Green portfolio performance
4. Factor exposures and regression results
5. Cumulative portfolio performance
