### Project 2 — Conditional Lead-Lag Alpha

**A Risk-Constrained Long-Short Equity Strategy**

This project studies whether smaller firms exhibit continuation following common industry information but reversal following exposure to leader-specific residual shocks.

The project develops the idea from signal identification through portfolio construction, risk management, transaction costs, robustness testing, and out-of-sample evaluation.

Folder:

`Project_2_Conditional_Lead_Lag_Alpha/`
